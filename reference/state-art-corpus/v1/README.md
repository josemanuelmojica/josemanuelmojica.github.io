# Quiet Watersheds v1

This folder is the review/provenance companion to the runtime 50-state corpus in `public/maps/us-state-studies/v1/`.

- `contact-sheet.webp` shows all 50 generated plates in alphabetical order.
- `ALGORITHMIC_PHILOSOPHY.md` records the visual/computational direction copied from `docs/art/STATE_INK_ALGORITHMIC_PHILOSOPHY.md`.
- `PROVENANCE.json` pins the generator, geometry, source hashes, output manifest, and known limitations.

The runtime set contains one 1200×900 SVG master and one 1200×900 WebP per state. It is ready for a future interview response such as Boise → `US-ID`, but the NLP/geocoding interview itself is not implemented.
