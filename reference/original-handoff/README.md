# Eight Impressions — ChatGPT Sites handoff

This package is the complete creative and technical brief for a one-route, single-scroll website using eight real city networks in one Japanese Ink treatment.

## Start here

1. Upload `japanese-ink-sites-assets.zip` to the new ChatGPT Sites task.
2. Paste the contents of `MASTER_PROMPT.md` as the build request.
3. If Sites asks for clarification, answer that the supplied assets and copy are final and it should use the performance-ready `active-*` files.
4. Review the first build against `QA_CHECKLIST.md`.
5. Use the focused prompts in `FOLLOW_UP_PROMPTS.md` for corrections instead of asking for a general redesign.

## Included guidance

- `MASTER_PROMPT.md` — complete copy/paste Sites build prompt.
- `INTERACTION_SPEC.md` — scroll phases, map blending, mobile, accessibility, and performance rules.
- `COPY_DECK.md` — final page copy and accessible location labels.
- `ASSET_GUIDE.md` — exactly which files to upload and which archival files not to load.
- `DESIGN_TOKENS.css` — palette, type stacks, spacing, and easing values.
- `COMPONENT_BLUEPRINT.md` — recommended one-route React component structure.
- `QA_CHECKLIST.md` — visual, interaction, performance, and accessibility acceptance criteria.
- `FOLLOW_UP_PROMPTS.md` — precise prompts for the common second-pass fixes.

## Creative thesis

One sheet of paper receives eight impressions. Each location remains still long enough to read, then selected streets lift toward a single vermilion seal point. The next network develops outward from that same point. The visitor should feel one uninterrupted drawing changing its mind—not eight slides, tabs, or pages.

The website has one memorable gesture: the seal transition. Everything else stays quiet.
